# Cosmocrat OS website positioning

The owner approved the Cosmocrat OS website direction and release on October 30, 2026. Cosmocrat OS is the public project and tool-family identity for AI work under human direction. The original philosophy remains: human sovereignty, memory as infrastructure, inspectable trust, context boundaries and reliable continuation.

Orion Estate is the private operating environment that informs the work. The Orion tools retain their names, repositories, independent versions, licenses and support boundaries. The catalog connects each release to its correct guide and any verified companion video. The Starter development-evidence guide uses 0.3.0-rc.1; the earlier continuity guide/video remain pinned to 0.2.0-rc.1.

The governance kernel keeps its narrow policy, mutation-authority, fail-closed admission, authoritative decision-receipt and audit responsibilities. Execution remains outside it. Tool-family membership establishes no kernel integration, runtime adoption, comprehensive isolation or enforcement without bypass paths. Local observations, governance admission and external outcomes remain distinct.

Independent tools are available; selected Starter combinations remain previews and public Remote Hands is experimental/start-only. There is no complete OS installer or universal platform support promise. Existing governance URLs explain architecture and integration scope. The public website's broader identity does not alter kernel contracts or release another package, guide or video.
